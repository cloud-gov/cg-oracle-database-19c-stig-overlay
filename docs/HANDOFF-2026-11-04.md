At `SQL>`, run (share the complete resulting *profile/limit* tables and any
errors; user counts are optional and no usernames are needed):

```sql
SET LINESIZE 200
SET PAGESIZE 200
SELECT p.profile, p.limit AS sessions_per_user
FROM dba_profiles p
WHERE p.resource_name = 'SESSIONS_PER_USER'
ORDER BY p.profile;

SELECT life.profile,
       life.limit AS password_life_time,
       grace.limit AS password_grace_time,
       CASE
         WHEN DECODE(life.limit, 'DEFAULT', default_life.limit, life.limit) = 'UNLIMITED'
           OR DECODE(grace.limit, 'DEFAULT', default_grace.limit, grace.limit) = 'UNLIMITED'
           THEN 'UNLIMITED'
         ELSE TO_CHAR(
           TO_NUMBER(DECODE(life.limit, 'DEFAULT', default_life.limit, life.limit)) +
           TO_NUMBER(DECODE(grace.limit, 'DEFAULT', default_grace.limit, grace.limit)))
       END AS effective_life_time
FROM dba_profiles life
JOIN dba_profiles grace
  ON grace.profile = life.profile AND grace.resource_name = 'PASSWORD_GRACE_TIME'
JOIN dba_profiles default_life
  ON default_life.profile = 'DEFAULT' AND default_life.resource_name = 'PASSWORD_LIFE_TIME'
JOIN dba_profiles default_grace
  ON default_grace.profile = 'DEFAULT' AND default_grace.resource_name = 'PASSWORD_GRACE_TIME'
WHERE life.resource_name = 'PASSWORD_LIFE_TIME'
ORDER BY life.profile;
```

profile;` (no usernames). `SV-270563` also assesses unused profiles, following
